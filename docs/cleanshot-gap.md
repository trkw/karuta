# CleanShot X と Karuta の機能差

CleanShot X（5.x 時点）の公開情報から挙動を洗い出し、Karuta との差をまとめたものです。
コード・バイナリ・素材は一切使わず、公式の機能ページ・changelog・URL スキーム API ドキュメント・
ショートカット一覧から読み取れる挙動だけを元にしています。OCR と Cloud は作らない方針なので除外しています。

参照した公開情報:

- 機能一覧 https://cleanshot.com/features
- changelog https://cleanshot.com/changelog （旧 https://www.getcleanshot.com/changelog ）
- URL スキーム API https://cleanshot.com/docs-api
- ショートカット一覧 https://www.pie-menu.com/shortcuts/cleanshot

記号: ✅ 実装済み / △ 一部 / ❌ 未実装 / ★ v0.9.0 / ☆ v0.9.1

## 実装の順番

1. **v0.9.0（今回）**: セルフタイマー、「範囲を撮影して〜」ショートカット、⌃ でコピー、クリップボード / ファイルを開く、ファイルをピン留め、最近閉じたものを戻す、オーバーレイの右クリックメニューと一括ショートカット
2. ☆ v0.9.1: カーソルを写す、ファイル名テンプレート、Retina 1x、HEIC → 続けて All-In-One モード（サイズ指定・縦横比固定）
3. 撮影履歴（ディスク保存・一覧ウィンドウ）
4. ピン留めの強化（右クリック・ロック・矢印キー・一括）とオーバーレイの位置・サイズ
5. エディタの強化（矢印・文字スタイル、黒塗り、回転・反転、⌘D、色の保存）
6. URL スキーム API
7. 画面収録（MP4 → GIF → クリック・キー表示 → 音声）
8. スクロールキャプチャ
